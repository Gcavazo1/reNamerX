# reNamerX Documentation

This directory contains documentation files for reNamerX that will be integrated into the website.

## Documentation Structure

- `getting-started.md`: Installation and first steps
- `features.md`: Detailed feature documentation
- `usage-guide.md`: How to use reNamerX effectively
- `faq.md`: Frequently asked questions
- `troubleshooting.md`: Common issues and solutions
- `api.md`: API documentation for developers

## Converting to Website Pages

These markdown files will be used to generate the documentation section of the website. Each file will be converted to a page in the site's `/docs` section.
